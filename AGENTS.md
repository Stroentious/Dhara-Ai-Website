# DHARA AI - Agent & System Execution Guidelines

## STRICT PROCESS & SERVER CONTROL

- **No Automatic Server / Process Startup**:
  - NEVER automatically start Vite, React dev server, Python backend, FastAPI, Uvicorn, background workers, or localhost services.
  - NEVER open browser windows or previews automatically.
- **Manual Launch Only**:
  - The developer retains 100% control over when processes start.
  - Processes must only start when the user explicitly runs manual commands.
